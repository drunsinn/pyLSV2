FN 16 output parser
===================

The :class:`pyLSV2.fn16_parser.FN16Parser` reads output generated by the
HEIDENHAIN ``FN 16: F-PRINT`` function. It uses the format file (usually a
file with the ``.a`` extension) to interpret the corresponding output file
(usually ``.txt``) and returns a structured document containing blocks and
events.

The parser does not execute FN 16 or recreate the control's file handling. It
works on files that have already been generated by the control or its
simulation.

Using the parser
----------------

Create a parser with the format file and parse the output file::

    from pyLSV2.fn16_parser import FN16Parser

    parser = FN16Parser("Format.a")
    document = parser.parse_output("Output.txt")

The result is an :class:`pyLSV2.fn16_parser.FN16Document`. Its ``blocks``
contain :class:`pyLSV2.fn16_parser.FN16Block` objects. Each block contains
``FN16Event`` objects of these types:

``context``
    A control or language keyword from the format file. The keyword is
    available as the event's ``command`` attribute.
``text``
    A fixed-text line from the format file. The output line is available as
    ``raw``.
``data``
    A formatted line. ``raw`` contains the output line and ``values`` maps
    each named parameter to its parsed Python value.

Blocks are separated by ``M_APPEND`` and ``M_APPEND_MAX`` keywords. ``M_CLOSE``
and ``M_TRUNCATE`` finish the parsed document. A block may contain several
data events; the CSV command combines those events into one row.

Format-file syntax
------------------

A format file contains quoted output lines, followed by comma-separated
parameter names when the line contains placeholders. A semicolon terminates
the line and an asterisk starts a comment. For example::

    "DATE: %02d.%02d.%04d", DAY, MONTH, YEAR4;
    "Value: %15.2f", Q1;
    "Message: %s", QS1;
    M_APPEND;
    M_CLOSE;

The supported placeholders are:

``%d`` or ``%i``
    Integer values. Widths such as ``%02d`` are accepted. Lowercase ``%d``
    is retained for compatibility with existing FN 16 files.
``%D`` or ``%F``
    Floating-point values. Precision and width, for example ``%15.2f``, are
    accepted. Scientific notation in the output is also supported.
``%S`` or ``%RS``
    String values. Widths such as ``%15s`` are accepted; surrounding output
    padding is removed from the value.

The format text also supports the documented escaped literals ``%%`` for a
percent sign, ``%\"`` for a quotation mark, ``\\`` for a backslash, and ``\\n``
for a line break within one logical format record. ``+`` and ``-`` alignment
flags and numeric formatting flags are accepted when matching output.

The parser recognizes the block and empty-line keywords ``M_APPEND``,
``M_APPEND_MAX``, ``M_CLOSE``, ``M_TRUNCATE``, ``M_EMPTY_HIDE`` and
``M_EMPTY_SHOW``. Language keywords are retained as context events. Date/time
names such as ``DAY``, ``MONTH``, ``YEAR4``, ``HOUR`` and ``MIN`` are treated
like other named values because their values are read from the output file.

Converting to CSV
-----------------

The ``fn16tocsv`` command converts all data events into a CSV file. It uses
the named parameters as columns and combines data events from each parsed
block into one row::

    uv run fn16tocsv Format.a Output.txt Output.csv

The third argument is optional. If it is omitted, the CSV file receives the
output file's name with a ``.csv`` extension::

    uv run fn16tocsv Format.a Output.txt

The command returns an error when no parsed data values are present. This is
expected for format files containing only fixed text or keywords, because
there are no placeholder values from which CSV columns or rows could be
created. Missing values in a row are written as empty CSV fields.

Python API
----------

The conversion function is also available directly::

    from pyLSV2.scripts.fn16_to_csv import convert_fn16_output_to_csv

    convert_fn16_output_to_csv(
        "Format.a",
        "Output.txt",
        "Output.csv",
    )

The parser and converter use UTF-8 input and output files.
